# لوحة DOpad

لوحة تحكم محلية صغيرة لـ DOpad. تعمل على حاسوبك وتُفتح في المتصفح الافتراضي،
ولا تتصل إلا بـ `127.0.0.1` — أي أنها لا تنشر أي خادم على الشبكة.

تستطيع اللوحة:

- التبديل بين أوضاع **Wi‑Fi** و**Bluetooth** و**Self**؛
- تشغيل خادم DOpad وإيقافه وعرض سجله ورمز QR الحيّ؛
- قراءة الأزرار والأيقونات وأنواع العناصر وخصائصها من `web/controls.js` وقت
  التشغيل (بلا نسخة مكررة من الكتالوج)؛
- تحرير التخطيط بصريًا (سحب، تغيير حجم، إضافة/حذف عناصر وأجزاء الإطار)؛
- تحميل وحفظ التخطيطات في `layouts/<id>.json`؛
- تصدير التخطيط الحالي كملف `.json` واستيراده مرة أخرى.

## المتطلبات

- Go 1.23 أو أحدث.
- ملف `DOpad` التنفيذي مبنيًا (`make build` في جذر المشروع)، أو تحديد مساره
  يدويًا.
- تُبنى اللوحة على لينكس وويندوز وماك. أما DOpad نفسه فيستهدف لينكس وويندوز،
  ووضع Self متاح على لينكس فقط.

## البناء

من جذر المشروع، يبني `make build` البرنامجين جنبًا إلى جنب:

```sh
make build
# ./DOpad
# ./dopad-panel
```

لبناء اللوحة وحدها:

```sh
make build-panel
```

ويمكنك بناؤها مباشرة من مجلدها:

```sh
cd gui/panel
go build -o ../../dopad-panel .
```

لتضمين رقم الإصدار:

```sh
make build-panel PANEL_VERSION=0.9.4
```

ويضع `make dist` أيضًا `dopad-panel` (أو `dopad-panel.exe`) في كل حزم لينكس
وويندوز.

ويندوز (بناء متقاطع من لينكس أو بناء مباشر على ويندوز):

```sh
cd gui/panel
GOOS=windows GOARCH=amd64 go build -o ../../dopad-panel.exe .
```

واجهة الويب مضمّنة عبر `go:embed`، لذا الناتج ملف تنفيذي واحد.

## التشغيل

```sh
./dopad-panel
```

تربط اللوحة منفذًا حرًا عشوائيًا على `127.0.0.1`، تطبع العنوان، وتفتح المتصفح
الافتراضي. الخيارات:

| الخيار | المعنى |
| --- | --- |
| `-port 8765` | منفذ ثابت للوحة (الافتراضي `0` = منفذ حر عشوائي). |
| `-no-open` | لا تفتح المتصفح تلقائيًا. |
| `-root /path/to/dopad` | جذر المشروع صراحةً. |
| `-version` | اطبع إصدار اللوحة واخرج. |

جذر المشروع هو المجلد الذي يحتوي `web/controls.js`. تفحص اللوحة `-root` ثم
`DOPAD_ROOT` ثم موقع الملف التنفيذي ثم مجلد العمل. ويُؤخذ ملف DOpad من
`DOPAD_BIN` أو يُكتشف تلقائيًا في جذر المشروع أو `server/` أو أحدث بناء غير
`+web` داخل `dist/`.

تعرض صفحة **الخادم** رمز QR الحيّ: تطلبه اللوحة من مسار `/qr` في DOpad نفسه
وتعرضه كصورة. في وضع البلوتوث يظهر الرمز بعد اتصال أول هاتف، وقبل ذلك تعرض
البطاقة تنبيهًا بذلك.

## الأوضاع

| الوضع | الأمر | ملاحظات |
| --- | --- | --- |
| Wi‑Fi | `./DOpad` | الهاتف والحاسوب على الشبكة المحلية نفسها. |
| Bluetooth | `./DOpad -b` | اتصال مباشر عبر بلوتوث (PAN). |
| Self | `sudo ./DOpad -s` | لينكس فقط؛ يصبح الحاسوب نقطة اتصال Wi‑Fi. |

وضع Self يحتاج صلاحيات root. أمامك ثلاثة خيارات:

1. تشغيل اللوحة نفسها بالأمر `sudo ./dopad-panel` للتحكم المباشر.
2. إدخال كلمة مرور sudo في اللوحة. تبقى في الذاكرة فقط وتُمسح عند إيقاف
   الخادم، ولا تُكتب على القرص أبدًا.
3. ترك `pkexec` يطلب تأكيدًا رسوميًا. قد يطلب التأكيد مرة أخرى عند الإيقاف لأن
   اللوحة لا تحتفظ بكلمة المرور.

## التخطيطات والمحرر

يقرأ المحرر الكتالوج من `web/controls.js` عند كل تحميل أو عند الضغط على
**تحديث**. وإضافة عنصر تستخدم القيم الافتراضية المستخرجة من الملف نفسه، ليبقى
كل شيء متوافقًا مع واجهة الخادم.

- **حفظ** يكتب `layouts/<id>.json`.
- **تصدير JSON** ينزّل `<id>.json` من المتصفح.
- **استيراد JSON** يحمّل ملف `.json` إلى المحرر؛ احفظه ليبقى.
- معرّف التخطيط يقبل حروفًا إنجليزية وأرقامًا و`.` و`_` و`-`.

الملف المحفوظ هو نفسه التنسيق الذي يتوقعه الخادم:

```json
{
  "name": "تخطيطي",
  "elements": [
    { "type": "button", "key": "A", "anchor": "cc", "x": 0, "y": 0 }
  ]
}
```

## الأمان

- تستمع على `127.0.0.1` فقط؛ لا يوجد أي خدمة عبر الإنترنت.
- كل طلب API يحتاج رمزًا عشوائيًا لكل تشغيل، يُحقن في الصفحة.
- يجب أن يأتي طلب API من `Host` و`Origin` محليين (loopback).
- كلمة مرور sudo لا تُحفظ.
- تُحفظ الإعدادات ببساطة في `layouts/panel/settings.json` داخل مجلد التخطيطات.
  المجلد الفرعي `panel/` يمنع ظهور الملف ضمن قائمة تخطيطات DOpad، وهو متجاهَل
  في Git.

اللوحة لا تعدّل `server/` ولا أي حزمة جاهزة. إنها تشغّل الملف التنفيذي الذي
تحدده وتكتب ملفات تخطيطات JSON فقط.

## حل المشكلات

- **«لم أجد ملف DOpad التنفيذي»** — ابنِه بالأمر `make build` في جذر المشروع،
  أو اكتب مساره في اللوحة.
- **المنفذ مستخدم** — يختار DOpad منفذًا حرًا قريبًا تلقائيًا؛ ويُقرأ المنفذ
  الفعلي من سجله.
- **وضع Self لا يبدأ** — تأكد أنك على لينكس، وأن اللوحة تعمل كـ root أو أنك
  أدخلت كلمة مرور sudo أو أن `pkexec` متاح.
- **إيقاف Self يطلب كلمة المرور مرة أخرى** — هذا مسار `pkexec`؛ شغّل اللوحة
  كـ root أو استخدم حقل كلمة المرور لتجنّبه.
- **التخطيط لا يُحفظ** — استخدم حروفًا إنجليزية وأرقامًا و`.` و`_` و`-` فقط في
  اسم الملف.
